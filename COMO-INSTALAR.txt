======================================================================================
   GUIA RAPIDO: INSTALAR E ATUALIZAR O CONTROLE REMOTO NO COMPUTADOR DO PROPRESENTER 7
======================================================================================

Objetivo: o computador do ProPresenter (10.0.21.145) LIGA, o servidor do controle
remoto SOBE SOZINHO, e o operador so abre o endereco no iPad/celular:

        http://10.0.21.145:3000

Precisa de: Windows 10/11, Git e Node.js 18+ (o instalador tenta instalar o Node;
para o Git: winget install --id Git.Git).

--------------------------------------------------------------------------------------
1) INSTALACAO NOVA  (PowerShell como ADMINISTRADOR)
--------------------------------------------------------------------------------------
   git clone https://github.com/nicolasdasilvaesilva/propresenter7-remote-web.git C:\ProPresenter-Remote
   powershell -ExecutionPolicy Bypass -File C:\ProPresenter-Remote\scripts\Instalar-Servico.ps1

   O que acontece: acha o ProPresenter neste computador, guarda a configuracao,
   cria a tarefa "ProPresenter-Remote" (sobe ao LIGAR o Windows, sem janela, para todos
   os usuarios, reinicia se cair), libera a porta 3000 no firewall, inicia e confere.

   Sem Administrador funciona, mas so sobe depois que um usuario entra no Windows.

--------------------------------------------------------------------------------------
2) JA TENHO A VERSAO ANTIGA (pasta ProPresenter-Remote-Deploy)  (PowerShell como ADMINISTRADOR)
--------------------------------------------------------------------------------------
   cd "C:\caminho\da\pasta\ProPresenter-Remote-Deploy"
   git pull origin main
   powershell -ExecutionPolicy Bypass -File .\scripts\Instalar-Servico.ps1

   Isso troca o inicializador antigo (pasta "Inicializar") pela tarefa nova.
   Depois de instalar, de 2 cliques em Instalar-Skill.bat (instala as skills no Antigravity).

--------------------------------------------------------------------------------------
3) ATUALIZAR PARA UMA VERSAO NOVA  (2 cliques, como Administrador)
--------------------------------------------------------------------------------------
   Atualizar-Controle-Remoto.bat  (botao direito > Executar como administrador)

   Faz: backup, baixa do GitHub, atualiza, reinicia, CONFERE. Se algo falhar, volta
   sozinho para a versao anterior. A versao dos arquivos muda sozinha, entao os
   aparelhos nao ficam com a versao antiga (feche e abra o app no iPad).
   Na 1a vez depois da migracao rode antes:  git pull origin main

--------------------------------------------------------------------------------------
4) CONFERIR / PARAR / REMOVER
--------------------------------------------------------------------------------------
   Verificar-Controle-Remoto.bat          confere tudo e mostra os enderecos
   Parar-Controle-Remoto.bat              para SO o controle remoto
   Desinstalar-Inicio-Automatico.bat      remove o inicio automatico (mantem arquivos)
   Iniciar-Controle-Remoto.bat            roda em primeiro plano (teste)

--------------------------------------------------------------------------------------
5) PEDIR AO CLAUDE CODE OU AO ANTIGRAVITY FAZER TUDO SOZINHO
--------------------------------------------------------------------------------------
   Rode Instalar-Skill.bat (instala as skills no Claude Code e no Antigravity), abra o
   assistente (como Administrador), cole o texto de PROMPT-PARA-ANTIGRAVITY.txt e ele
   instala, atualiza e confere usando as skills (propresenter-remote-install).
   Porta padrao do servidor: 3000.

--------------------------------------------------------------------------------------
6) SE ALGO NAO FUNCIONAR
--------------------------------------------------------------------------------------
   - Rode Verificar-Controle-Remoto.bat: ele diz o que esta errado.
   - iPad nao abre: firewall / rede do Windows como "Publica" (mude para "Privada").
   - "Versao antiga" no iPad: feche e abra o app; ou recarregue 2 vezes.
   - Logs: pasta logs\  (server.log e server-erro.log)
======================================================================================
